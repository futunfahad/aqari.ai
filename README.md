# Aqari.ai

Machine Learning Meets Riyadh Real Estate: An Empirical PerspectiveMachine Learning Meets Riyadh Real Estate: An Empirical Perspective

This project leverages machine learning to analyze and predict real estate prices in the Riyadh market. Data was programmatically collected from the official Aqar platform using web scraping with Python’s requests library and the Aqar API. After rigorous data cleaning and preprocessing, several predictive modeling techniques were applied, including Gradient Boosting Regression, Random Forest, and Quantile Regression, to accurately estimate property prices based on features such as area, number of rooms, room type, and property type.

The team tackled challenges such as outlier detection and feature engineering to improve model performance. For deployment and user interaction, a user-friendly web interface was developed using Gradio and Hugging Face, enabling real-time property price predictions and accessible model insights. Additional exploratory data analysis and visualization were conducted using ggplot2, Leaflet, and Shiny in R to create interactive maps and visual summaries.

Key Tools & Technologies:

Data Acquisition: Python (requests, Aqar API), Web Scraping

Modeling: Scikit-learn (Gradient Boosting, Random Forest, Quantile Regression)

Interface: Gradio, Hugging Face

Visualization: R (ggplot2, Leaflet, Shiny)

Other: Data cleaning, outlier detection, feature engineering
